If getting the "private email" fatal error: 

git config --global user.email "12345678+yourusername@users.noreply.github.com" #found in github settings > email
git config --global user.name "Your Name" 

Then run this to check with email github is trying to use for the commit: 
git log -1 --format='Author: %ae%nCommitter: %ce'

If the email (or username) show your real email, run this: 
git commit --amend --reset-author --no-edit 

then commit the file via
git add .
git commit
git push

when using git commit, you will have to add a note. If you just try to start typing, it won't work. Ctrl+i lets you insert, but pressing s also works.
