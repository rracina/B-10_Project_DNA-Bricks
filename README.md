# KTH - CB2442: B-10 Project: DNA-Bricks
CB2330 Group Project: Group 13, Paper ID B-10

This project used the "Three-Dimensional Structures Self-Assembled from DNA Bricks" (Ke et al., 2012) article as the baseline for exploring the relationship between generated DNA yield and $MgCL_2$ concentration in buffer solution.


## Concept
The proposed model is a gaussian approach. The forward simulation is used to simulate data points based on random numbers generated by a linear congruential generator to propose a gaussian predicitve curve, which is later fitted to the measured data. The backward simulation is using negative log-likelihood and grid search to be able to fit the simulated data to the observed data in the paper. The bootstrap is used to evaluate the model's confidence. 


## Findings
The proposed model is able to simulate the expected yields given $[MgCl_2]$ by using a Gaussian Distribution. It results in a optimal concentration of $MgCl_2$ for a maximum yield, which is confirmed to a 0.9 confidence level using a bootstrap with 350 samples.
